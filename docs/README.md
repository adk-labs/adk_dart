# ADK Dart Documentation

This directory is the canonical home for ADK Dart project documentation.

## Directories

- `knowledge/`: Long-lived reference material such as API matrices, parity
  checklists, and comparison tables.
- `worklog/`: Time-bound implementation notes, parity work units, sync reviews,
  verification logs, and commit-level execution records.

Do not add new root-level `doc/` or `knowledge/` directories. Put new work-unit
records in `docs/worklog/` and reusable reference material in `docs/knowledge/`.
