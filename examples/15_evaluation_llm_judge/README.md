# 15. Agent Evaluation & Benchmarking

Demonstrates automated agent response evaluation and benchmark testing using `LocalEvalService` and `EvalCase`.

## How to Run

```bash
cd examples/15_evaluation_llm_judge
dart pub get
dart run bin/main.dart
```

---

### 한국어
`LocalEvalService` 및 `EvalCase`를 활용하여 에이전트의 응답 퀄리티 및 기대 출력 일치도를 자동으로 평가하고 벤치마킹하는 예제입니다.

### 日本語
`LocalEvalService` および `EvalCase` を活用して、エージェントの応答品質や期待出力との一致度を自動評価・ベンチマークするサンプルです。

### 中文
利用 `LocalEvalService` 和 `EvalCase` 自动化评测智能体回复质量并进行基准测试的示例。
