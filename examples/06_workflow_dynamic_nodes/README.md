# 06. Workflow Dynamic Nodes

Demonstrates dynamic graph node creation, conditional scheduling, and runtime state propagation during workflow execution.

## How to Run

```bash
cd examples/06_workflow_dynamic_nodes
dart pub get
export GEMINI_API_KEY="your-gemini-api-key"
dart run bin/main.dart
```
