# 09. On-Device Gemma (LiteRT-LM)

Demonstrates purely on-device LLM inference using Google LiteRT-LM (Native C interop / FFI) without any network requests.

## How to Run

```bash
cd examples/09_local_llm_litert
dart pub get
dart run bin/main.dart
```

---

### 한국어
Google LiteRT-LM(네이티브 C API / FFI)을 활용하여 네트워크 통신 없이 온디바이스에서 경량 Gemma 모델을 직접 구동하는 예제입니다.

### 日本語
Google LiteRT-LM (ネイティブ C API / FFI) を活用し、ネットワーク通信なしでデバイス上で直接 Gemma モデルを駆動するサンプルです。

### 中文
利用 Google LiteRT-LM（原生 C API / FFI）在无网络连接的情况下在设备端直接运行 Gemma 模型的示例。
