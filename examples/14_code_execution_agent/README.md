# 14. Code Execution Agent

Demonstrates solving complex numerical, statistical, and algorithmic computations through runtime AST code generation and sandbox execution via `BuiltInCodeExecutor`.

## Execution

```bash
cd examples/14_code_execution_agent
dart pub get
export GEMINI_API_KEY="your-gemini-api-key"
dart run bin/main.dart
```

---

### 한국어
`BuiltInCodeExecutor`를 바인딩하여 복잡한 수치 해석, 통계 연산 및 동적 알고리즘 문제를 샌드박스 코드 생성 및 런타임 AST 실행을 통해 무오차로 해결하는 에이전트 예제입니다.

### 日本語
`BuiltInCodeExecutor` をバインドし、複雑な数値解析、統計計算、動的アルゴリズムの問題をサンドボックスコード生成およびランタイム AST 実行によって高精度に解決するサンプルです。

### 中文
绑定 `BuiltInCodeExecutor`，通过沙箱代码生成与运行时 AST 执行无误差解决复杂数值分析、统计运算与动态算法问题的智能体示例。
