# 14. Code Execution Agent

Demonstrates solving complex numerical, mathematical, and algorithmic problems through sandbox code execution via `BuiltInCodeExecutor`.

## How to Run

```bash
cd examples/14_code_execution_agent
dart pub get
export GEMINI_API_KEY="your-gemini-api-key"
dart run bin/main.dart
```
