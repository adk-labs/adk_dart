# 18. SQLite Session Persistence

Demonstrates robust conversation session persistence, export, and state preservation across process restarts using `SqliteSessionService`.

## How to Run

```bash
cd examples/18_sqlite_session_persistence
dart pub get
dart run bin/main.dart
```

---

### 한국어
`SqliteSessionService`를 활용하여 프로세스가 재시작되어도 대화 히스토리 및 세션 상태가 디스크(SQLite)에 안전하게 유지되는 에이전트 예제입니다.

### 日本語
`SqliteSessionService` を活用して、プロセスの再起動後も会話履歴とセッション状態がディスク (SQLite) に安全に保持されるエージェントサンプルです。

### 中文
利用 `SqliteSessionService` 在进程重启后仍将对话历史与会话状态安全保存在磁盘 (SQLite) 上的智能体示例。
