# 12. Structured Output Schema

Demonstrates forcing the agent to return strictly typed, JSON Schema compliant responses via `outputSchema`.

## How to Run

```bash
cd examples/12_structured_output_schema
dart pub get
export GEMINI_API_KEY="your-gemini-api-key"
dart run bin/main.dart
```

---

### 한국어
`outputSchema`를 사용하여 에이전트의 최종 출력을 엄격한 JSON 스키마 규격으로 제약하고 타입 안전하게 파싱하는 예제입니다.
